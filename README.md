# ORBITUNE - 3D Spatial Audio API

AI-powered 3D spatial audio processing backend with source separation, genre detection, and HRTF-based spatialization.

## Tech Stack

- **Backend**: FastAPI, Uvicorn
- **Audio Processing**: Demucs, Librosa, SoundFile, PyDub, Pedalboard, Noisereduce
- **AI/ML**: Google Generative AI (Gemini), PyTorch, TorchAudio
- **Storage**: Supabase (PostgreSQL + Storage)
- **Deployment**: Docker, Hugging Face Spaces
- **Utilities**: yt-dlp, python-multipart, aiofiles, python-dotenv, tqdm, requests
